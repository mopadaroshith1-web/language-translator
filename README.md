# 🌐 Language Translator

A simple and user-friendly **Language Translation Tool** built as a college/internship project.

The application allows users to enter text, select a source language and target language, and receive the translated text through a translation API.

## ✨ Features

- 🌍 Select source and target languages
- 🔄 Swap source and target languages
- 📝 Translate entered text
- 📋 Copy translated text
- 🔊 Listen to translated text using text-to-speech
- 🗑️ Clear input and translation
- 🔢 Character counter
- 📱 Responsive user interface
- ⚡ Node.js backend
- 🔐 Backend API request handling

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Frontend functionality
- **Node.js** — Backend server
- **Express.js** — Server framework
- **MyMemory Translation API** — Translation service
- **Git & GitHub** — Version control and project hosting
